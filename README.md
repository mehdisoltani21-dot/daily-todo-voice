# لیست کارهای روزانه صوتی 📋

یک اپلیکیشن ساده HTML برای مدیریت کارهای روزانه با قابلیت **ضبط صدا**.

## ویژگی‌ها
- 🎤 اضافه کردن کار با صدا (فارسی)
- ✍️ اضافه کردن دستی
- 📅 تاریخ ثبت و تاریخ سررسید
- ✅ علامت‌زدن کارهای انجام‌شده
- 💾 ذخیره خودکار در مرورگر (localStorage)

## نحوه استفاده
1. فایل `index.html` را باز کنید یا از GitHub Pages استفاده کنید
2. اجازه دسترسی به میکروفون را بدهید
3. روی دکمه ضبط صدا کلیک کنید و کارتان را بگویید
